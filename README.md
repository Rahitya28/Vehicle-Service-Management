# Vehicle-Service-Management

##  Project Description
The Vehicle Service Management System is a full-stack web application designed to simplify vehicle servicing operations.  

It allows users to manage their vehicles, book service appointments, and track service history, while administrators and technicians can manage and monitor service activities efficiently.

---

##  Objectives
- To provide an easy platform for booking vehicle services  
- To manage vehicle records digitally  
- To improve service tracking and transparency  
- To enable role-based system access (Customer, Technician, Admin)  

---

##  Key Features

### 👤 Customer
- Register and login securely  
- Add and manage vehicles  
- Book service appointments  
- View service history  

### 🛠 Technician
- View assigned service tasks  
- Update service status  
- Maintain service records  

### 🧑‍💼 Admin
- View dashboard statistics  
- Manage appointments  
- Assign technicians  
- Monitor overall system activity  

---

## 🛠️ Tech Stack

### 🔹 Frontend
- React.js  
- React Router  
- Axios  
- Tailwind CSS  

### 🔹 Backend
- Node.js  
- Express.js  

### 🔹 Database
- MongoDB (Mongoose)  

### 🔹 Authentication & Security
- JWT (JSON Web Token)  
- Bcrypt for password encryption  

---

##  System Architecture

The system follows a client-server architecture:

- Frontend (React) handles UI and user interaction  
- Backend (Node.js + Express) processes requests and business logic  
- Database (MongoDB) stores user, vehicle, and service data
